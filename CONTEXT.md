# CONTEXT — Постоянный контекст проекта MEDAS

---

## Проект

**Название:** MEDAS
**Описание:** Медицинская SaaS-платформа для записи к врачам — пациенты находят и записываются к врачу, клиники получают первичных пациентов (аналог СберЗдоровье / Напоправку)
**Тип:** SaaS-платформа / Маркетплейс медицинских услуг
**Стадия:** MVP
**Старт разработки:** 2026-06-10

---

## Цели

**Главная цель:** Запустить платформу с публичным поиском врачей, ЛК пациента/клиники/врача и системой записи + бонусов

**Метрики успеха:**
- [ ] 10+ клиник подключено к платформе
- [ ] 100+ записей через платформу в месяц
- [ ] Страницы врачей индексируются в Google (SEO)
- [ ] < 2с время загрузки публичных страниц

---

## Бизнес-модель

- **Клиники платят** за первичных пациентов (лиды) — подписка или CPA
- **Пациенты получают** бонусные баллы с каждой записи (удержание, повторные визиты)
- **Монетизация v2**: платное поднятие в поиске, рекламные блоки, баннеры
- **Типы клиентов**: стоматология, общая медицина, косметология, частные врачи

---

## Целевая аудитория

**Пациенты:** люди которым нужен врач, хотят выбрать по отзывам/рейтингу/цене/расположению
**Клиники/Врачи:** хотят получать новых пациентов без больших затрат на рекламу
**Главная проблема:** Найти хорошего врача сложно, записаться без звонка нельзя
**Альтернативы:** СберЗдоровье, Напоправку, Zoon, звонок в клинику напрямую

---

## Технический стек

**Frontend:** Next.js 15 (App Router)
- Стилизация: Tailwind CSS
- Компоненты: shadcn/ui
- Состояние: useState/Context + React Query
- TypeScript strict mode

**Backend:** FastAPI (Python 3.12)
- Язык: Python 3.12
- ORM: SQLAlchemy 2.0 async
- Валидация: Pydantic v2

**База данных:** PostgreSQL 16
- Поиск: PostgreSQL FTS (ts_vector) → Elasticsearch позже
- Кэш/сессии: Redis

**Авторизация:** JWT + refresh tokens (httpOnly cookies)

**Файловое хранилище:** MinIO (S3-совместимый, self-hosted) — фото врачей, документы

**Деплой:** Docker Compose + Nginx на VPS
- CI/CD: GitHub Actions (lint + build + deploy)

**Внешние сервисы:**
- Email: TBD (SendGrid / Unisender)
- Платежи: TBD (ЮКасса / Stripe)

## Ключевые ограничения

- Публичные страницы врачей/клиник должны быть SEO-оптимизированы (SSR/SSG)
- Запись к врачу — только после авторизации
- Бонусы не выводятся деньгами — только тратятся на платформе
- UI строго на русском языке

## Бизнес-правила

- Запись создаётся только если у пациента есть аккаунт
- Бонусы начисляются после состоявшегося визита (не при записи)
- Срок жизни бонусов: 12 месяцев с момента начисления
- Клиника видит данные пациента только после подтверждения записи
- Триал для клиник: бесплатно, лимит 10 лидов/месяц
