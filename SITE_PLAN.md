## 1. ПУБЛИЧНЫЕ СТРАНИЦЫ

### `/` — Главная страница ✅
**Статус:** Реализована по Stitch-дизайну

**Элементы:**
- Навигация: логотип MEDAS, пункты меню (Найти врача / Клиникам / Врачам / Акции), кнопки "Войти" + "Зарегистрироваться"
- Hero-блок: заголовок "Ваш здоровый выбор", подзаголовок, поиск (специальность + город + дата), CTA-кнопка "Найти врача"
- Блок специальностей: 8 категорий с иконками
- Блок "Как это работает": 4 шага (поиск → выбор → запись → приём)
- Блок врачей: карточки топ-4 врача с фото, рейтингом, специальностью, ценой
- Блок клиник: 3 карточки с логотипом, рейтингом, количеством врачей
- Блок бонусов: описание программы лояльности, пример накопления
- Footer: навигация, контакты, соцсети, copyright

**Функционал:**
- Поиск на главной → redirect на `/search?q=...`
- Быстрые кнопки специальностей → `/search?specialty=...`

**Ещё не реализовано:**
- Мобильное меню (гамбургер)
- Реальный поиск (сейчас только форма)
- Акции/баннеры

---

### `/search` — Поиск врачей ✅
**Статус:** Реализована, статические данные

**Элементы:**
- Breadcrumb: Главная / Поиск врачей
- Сайдбар фильтров (1/4 ширины):
  - Специальность (checkboxes)
  - Доступность (сегодня / эта неделя / любое время)
  - Опыт работы (слайдер: 1 / 5 / 10+ лет)
  - Цена за приём (слайдер или ввод: от/до)
  - Вызов на дом (toggle)
  - Пол врача (Любой / М / Ж)
- Блок результатов (3/4 ширины):
  - Сортировка (по рейтингу / цене / опыту)
  - Карточки врачей (9 шт): фото, имя, специальность, клиника, рейтинг, количество отзывов, опыт, цена, теги (Вызов на дом / Онлайн), кнопка "Записаться"
  - Пагинация

**Функционал:**
- Фильтрация → обновление списка
- "Записаться" → `/doctor/[slug]/booking`
- Клик по карточке → `/doctor/[slug]`

**Ещё не реализовано:**
- Реальный поиск по БД
- Карта врачей (альтернативный вид)
- Сохранение фильтров в URL-параметрах

### `/doctor/[slug]` — Профиль врача ✅
**Статус:** Реализована, статические данные

**Элементы:**
- Breadcrumb: Главная / Поиск / Имя врача
- Главная колонка (8/12):
  - Карточка врача: фото, имя, специальность, клиника, рейтинг, опыт, значки верификации
  - Вкладки: О враче / Образование / Отзывы / Цены
  - Секция "О враче": описание, специализации, процедуры
  - Секция "Образование": список с годами
  - Секция "Клиника": название, адрес, телефон, карта (placeholder)
  - Секция "Отзывы": список с аватарами, звёздами, текстом
- Правая колонка (4/12) — sticky виджет записи:
  - Цена приёма
  - Мини-календарь (7 дней вперёд)
  - Слоты времени (сетка 2 колонки)
  - Тип приёма: В клинике / Онлайн
  - Кнопка "Записаться" → `/doctor/[slug]/booking`

**Ещё не реализовано:**
- Динамическая загрузка по slug
- Реальный календарь доступных слотов
- Галерея врача
- SEO meta-теги (name, specialty)
