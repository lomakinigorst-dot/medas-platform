## Блок 0.7 — Красные линии (с последствиями)

**ПРОЦЕСС:**
❌ Нет списка задач перед tool call → Игорь попросит переделать, потеря 5+ мин на каждую ошибку
❌ Пропустил Блок 0.1 → работаешь без контекста прошлой сессии, риск дублирования и откатов
❌ «Жду подтверждения» + impl в одном ответе → план игнорируется, Игорь получает неожиданный код
❌ ✅ без реального теста (URL/curl) → баги попадают в прод незамеченными
❌ push без progress.md + memory в батче → следующая сессия без контекста, потеря часа работы
❌ /test N/A «рефакторинг/стили» при наличии .py/.ts/.tsx/.js → баги не ловятся
❌ CODE_MAP.md N/A при новом .py/.ts файле → карта кода устаревает, следующий Claude потеряется
❌ `claude skills` из Bash → зависший процесс, крашит систему
❌ `find /Users/igor` без `-maxdepth` → BFS по диску, валит систему

**ДЕПЛОЙ:**
❌ `docker compose up` вместо `./deploy.sh` → обходит migration checks и env-inject, риск потери данных
❌ `force-recreate` без проверки сетей → контейнер теряет внешние сети, сервис падает
❌ Проверять деплой только `curl -I 200` → не гарантирует что новый бандл загружен
❌ Backend через scp без docker cp → файл не попадает в работающий контейнер

- Не выходить за рамки задачи. Не рефакторить соседний код.
