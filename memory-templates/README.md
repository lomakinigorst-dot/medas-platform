# Memory Templates — Инструкция

## Что это

Шаблоны файлов памяти для Claude Code. Память хранится НЕ в папке проекта, а в специальной директории Claude Code — отдельно для каждого проекта.

## Куда копировать

1. Узнай путь к памяти своего проекта. Он формируется из пути к проекту:
   ```
   ~/.claude/projects/[encoded-project-path]/memory/
   ```

   Например, если проект лежит в `/Users/igor/Documents/my-project`, путь к памяти:
   ```
   /Users/igor/.claude/projects/-Users-igor-Documents-my-project/memory/
   ```
   (слэши → дефисы, пробелы → дефисы)

2. Создай папку memory:
   ```bash
   mkdir -p ~/.claude/projects/-Users-[username]-[path-to-project]/memory/
   ```

3. Скопируй все `.md` файлы из этой папки (кроме README.md) в созданную папку.

4. Открой каждый файл и заполни плейсхолдеры в квадратных скобках.

## Файлы в этой папке

| Файл | Назначение |
|---|---|
| `MEMORY.md` | Индекс всех файлов памяти — Claude читает его первым |
| `user_profile.md` | Кто ты, твои предпочтения, опыт, как лучше с тобой работать |
| `project_status.md` | Текущий статус разработки, что сделано, что в процессе |
| `feedback_rules.md` | Правила которые Claude должен соблюдать по твоей обратной связи |

## Как это работает

Claude Code автоматически читает файлы из папки memory при старте сессии. Чем лучше заполнены файлы — тем лучше Claude понимает контекст без повторных объяснений.

После каждой рабочей сессии Claude обновляет `project_status.md` — фиксирует что было сделано.
